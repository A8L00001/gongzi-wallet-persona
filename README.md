# 工资去哪儿了？—— 打工人钱包人格测试

TRAE 1024 代码盲盒挑战参赛作品。关键词：**工资** / **小测验** / **多巴胺撞色风**。

一个纯前端、零构建依赖的娱乐向人格测试网站：8 道职场情景题 → 四维钱包人格雷达 → 可下载的结果海报。

## 一、运行说明

### 方式 1：直接打开（最快）

双击 `index.html`，或用浏览器打开：

```
file:///d:/Test Code/trae/gongzi-wallet-persona/index.html
```

> 直接打开时功能完整可用（无网络请求、无后端）。个别浏览器在 `file://` 下会限制 localStorage，
> 此时「上次结果」不可用，页面会提示，不影响测试与海报导出。

### 方式 2：本地静态服务器（推荐，localStorage 行为与线上一致）

任选一种，在项目根目录执行：

```powershell
# 有 Node.js
npx --yes serve . -l 8123

# 有 Python
python -m http.server 8123
```

然后访问 `http://127.0.0.1:8123/`。

### 环境要求

- 任意现代浏览器（Chrome / Edge / Firefox / Safari 近两年版本）
- 无需 Node、无需 npm install、无需构建、无数据库、无登录

## 三、玩法与算法

### 试题结构

| # | 情景 | # | 情景 |
|---|------|---|------|
| 1 | 工资到账 | 5 | 周五加班 |
| 2 | 深夜消费 | 6 | 年终奖 |
| 3 | 余额盘点 | 7 | 职业选择 |
| 4 | 涨薪谈判 | 8 | 存钱目标 |
| 1024 | 隐藏关卡（彩蛋解锁后追加） | | |

### 计分规则

- 每个选项 4 分 = **主权重 3 分** + **副权重 1 分**，分别投给两个维度。
- 每道题的 4 个副权重覆盖全部四个维度，因此四种人格理论满分相同（各 24 分）。
- 四维总分恒为 32 分，雷达图按 `得分 / 该维度理论满分` 归一化。

### 并列裁决（确定性，绝不随机）

取最高分者；若并列，按以下顺序依次裁决，并把裁决依据展示在结果页：

1. **第 1 题优先**：第 1 题（工资到账那一刻）最能代表钱包人格，其主类型在并列集合中即胜出。
2. **主类型命中次数**：并列各方中「被首选次数」更多者胜出。
3. **固定优先级兜底**：规划 > 谈判 > 存钱 > 月光（同一份答案永远得到同一个结果）。

全量枚举 4⁸ = 65536 种作答的实测分布：

| 人格 | 占比 | 人格 | 占比 |
|------|------|------|------|
| 月光冲锋员 | 24.8% | 涨薪谈判王 | 25.2% |
| 存钱守护者 | 24.8% | 财富规划师 | 25.2% |

其中 90.8% 一次判定，9.2% 进入并列裁决（第 1 题规则 8.1% / 命中次数 0.2% / 优先级 0.9%）。

## 五、实现要点

- **零依赖**：全部手写，无框架、无 CDN、无构建；断网可用。
- **海报导出**：不使用 html2canvas，直接用 Canvas 2D 逐层绘制（圆角矩形、斜条纹、网点底纹、
  雷达图、中文按字符折行），因此不受第三方脚本影响，`toDataURL('image/png')` 必定可用。
- **动效性能**：只动画 `transform / opacity`，彩纸粒子数按屏幕宽度调整，
  3.2 秒后自动回收并清空画布；`prefers-reduced-motion` 下全部关闭。
- **可访问性**：选项使用 `role="radio"` + `aria-checked`，进度条带 `role="progressbar"`
  与动态 `aria-valuenow`，弹窗 `role="dialog"` + Esc 关闭 + 焦点回归，键盘可全程操作。
- **本地存储**：`localStorage` 键 `gzmoney.result.v1` / `gzmoney.nickname.v1` / `gzmoney.egg1024.v1`，
  全部读写包在 try/catch 中，隐私模式下自动降级并提示。
